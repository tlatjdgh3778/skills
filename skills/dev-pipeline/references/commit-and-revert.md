# 커밋과 되돌리기 (9단계)

## 커밋
- 사용자 승인 후에만 커밋한다. 기능 단위로 커밋한다.
- 커밋 메시지 형식과 브랜치 규칙은 프로젝트의 지침 파일(`CLAUDE.md`, `AGENTS.md`, 기여 가이드)과 기존 커밋 이력(`git log`)의 관례를 따른다.
- 푸시는 사용자가 요청할 때만 한다. force-push와 `reset`은 쓰지 않는다.
- 부검 결과로 만든 수정과 부검 보고서는 같은 커밋에 포함한다.

## 되돌리기
배포 이후 또는 다음 단계로 승급하는 과정에서 문제가 발생하면:
1. 해당 커밋을 `git revert`로 되돌린다. force-push와 `reset`은 쓰지 않는다.
2. 재배포가 필요하면 프로젝트가 정한 공식 배포 절차만 쓴다(수동 명령 조합 금지). 절차를 모르면 사용자에게 확인한다.
3. 문제를 재현 절차와 관련 커밋 해시와 함께 기록하고(프로젝트의 이슈 관리 도구가 있으면 거기에) 10단계(부검)로 넘어간다.
